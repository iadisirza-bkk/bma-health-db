# รายงานการวิเคราะห์ตัวแปร: รองผู้ว่าราชการกรุงเทพมหานคร

> **บทบาท:** รับผิดชอบกำกับดูแลด้านสาธารณสุขเชิงปฏิบัติการ — ต้องการข้อมูลเปรียบเทียบระหว่างเขต ติดตามผลงาน KPI ศูนย์บริการ และระบุ gap ที่ต้องแก้ไข
>
> **แหล่งข้อมูล:** homehealth.csv · homevisit.csv · labhealth.csv · labhealthext.csv · pt.csv · pthistory.csv · vitalsignslf.csv

## ส่วนที่ 1: แผนที่ กทม (Map Dashboard)

### 1.1 ประสิทธิภาพศูนย์บริการสาธารณสุข (ทุกไฟล์)

| ตัวแปร | แหล่ง | สิ่งที่แสดงบนแผนที่ |
|---|---|---|
| `HPTCODE` | ทุกไฟล์ | Pin แต่ละศูนย์ — สีตามปริมาณงาน (เขียว=ปกติ, แดง=overload) |
| `PID` | ทุกไฟล์ | จำนวนผู้รับบริการ unique ต่อศูนย์ — ขนาด bubble |
| `VSTDATE`, `VSTTIME` | ทุกไฟล์ | Heatmap ช่วงเวลาให้บริการ — ระบุศูนย์ที่มี peak สูง |
| `FIRSTSTF`, `LASTSTF` | ทุกไฟล์ | จำนวนเจ้าหน้าที่ต่อศูนย์ — วัด staff-to-patient ratio |
| `CANCELST`, `CANCELSTF`, `CANCELDATE` | ทุกไฟล์ | อัตราการยกเลิก/ขาดนัดต่อศูนย์ — สีแดงถ้าสูงเกินเกณฑ์ |

| `DISTRICTBKK` | vitalsignslf.csv | แบ่งเขตบนแผนที่ — ใช้เปรียบเทียบประสิทธิภาพ |
| `LOCATION` | vitalsignslf.csv | จุดให้บริการ (ศูนย์/เชิงรุก) |
| `ORGBMA` | homevisit.csv | หน่วยงาน กทม ที่รับผิดชอบ |
