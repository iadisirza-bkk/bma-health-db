# รายงานการวิเคราะห์ตัวแปร: ผู้ว่าราชการกรุงเทพมหานคร

> **บทบาท:** ผู้บริหารสูงสุดของ กทม — ต้องการภาพรวมระดับนโยบาย เน้นตัวชี้วัดเชิงยุทธศาสตร์ ความครอบคลุมบริการ และแนวโน้มสุขภาพประชากรทั้ง 50 เขต
>
> **แหล่งข้อมูล:** homehealth.csv · homevisit.csv · labhealth.csv · labhealthext.csv · pt.csv · pthistory.csv · vitalsignslf.csv
>
> **ข้อมูลเสริม:** `clinic_latlong.xls` (14,092 สถานบริการ + พิกัด) · ArcGIS REST APIs 28 endpoints (เอกสารแนบ ๒) · PM2.5 API · แหล่งมลพิษ 9 ประเภท
>
> ---
>
> ### ประเด็นที่ผู้ว่า กทม ถามจริง (จากการประชุม)
> 1. **โรค x ที่อยู่อาศัย/สภาพแวดล้อม** — ความสัมพันธ์ของโรคกับพื้นที่ สภาพชุมชน ฝุ่น PM2.5
> 2. **พฤติกรรม x ผลลัพธ์สุขภาพ** — ออกกำลังกายแล้วไม่อ้วนจริงไหม? กินเค็มแล้วเป็นความดันจริงไหม?
> 3. **ปัจจัยทั้งบวกและลบ** — อะไรที่ส่งผลดี อะไรที่ส่งผลร้ายต่อสุขภาพ

### 1.6 โรค x สภาพแวดล้อม x มลพิษ — Overlay Layer (ตอบคำถามผู้ว่า)

> **ประเด็นจากผู้ว่า:** "ความสัมพันธ์ของโรคกับที่อยู่อาศัย สภาพแวดล้อม ปริมาณฝุ่น PM2.5"

**ชั้นข้อมูล GIS ที่มีอยู่แล้ว (เอกสารแนบ ๒ — 28 endpoints):**

| ชั้นข้อมูล | ArcGIS Endpoint | Overlay กับอะไร |
|---|---|---|
| **PM2.5 (มลพิษอากาศ)** | bmagis — `air_quality_data_processed` (WKID 102100) | **DM, HPT, ASTH, EMPHY, CHEST ต่อเขต** — เขตที่ PM2.5 สูง มีโรคทางเดินหายใจมากกว่าไหม? |
| กิจการแพลนท์ปูน | bmamap — `dust_pollution/0` (WKID 4326) | ASTH, EMPHY — ใกล้โรงปูนหอบหืดมากขึ้นไหม? |
| โครงการก่อสร้าง 50 เขต | bmamap — `dust_pollution/1` | ASTH, CHEST — เขตก่อสร้างเยอะ ปอดมีปัญหามากขึ้นไหม? |
| โรงงานที่รายงาน รว.3 | bmamap — `dust_pollution/2` | DM, HPT, FAT — occupational health ในเขตโรงงาน |
| กิจการอู่พ่นสีรถยนต์ | bmamap — `dust_pollution/4` | ASTH, EMPHY — สารเคมีจากอู่พ่นสี |
| กิจการหลอมหรือหล่อโลหะ | bmamap — `dust_pollution/9` | โรคปอด, ค่าตับ (SGOT, SGPT) |
| จุดตรวจวัดควันดำ | bmamap — `dust_pollution/6` | Correlate ค่าควันดำกับ respiratory diseases |
| **ขอบเขตชุมชน** | cpudgiapp — `Community/Service_Community` Layer 14 | `HOMETYPE` x โรค — ชุมชนแออัดมี NCD สูงกว่าไหม? |
| โรงควบคุมคุณภาพน้ำ/บำบัดน้ำเสีย | cpudgiportal Layer 73 | `KIDNEY`, `UA` — ใกล้แหล่งน้ำเสียมีโรคไตมากขึ้นไหม? |
| ตลาดที่ขึ้นทะเบียน กทม. | cpudgiportal Layer 82 | `FDSW`, `FDSLT`, `FDFAT` — ใกล้ตลาดพฤติกรรมอาหารเปลี่ยนไหม? |

**วิธี Overlay บนแผนที่:**
1. Plot สถานบริการจาก `clinic_latlong.xls` (14,092 จุด, มี `lat`, `lng`)
2. ซ้อน PM2.5 heatmap จาก bmagis endpoint
3. ซ้อน disease prevalence per district จาก `DISTRICTBKK` (vitalsignslf.csv)
4. ซ้อนแหล่งมลพิษจาก bmamap endpoints
5. ใช้ spatial join: เขตที่มี PM2.5 สูง + มีแหล่งมลพิษเยอะ → ดูอัตรา ASTH/EMPHY/CHEST ผิดปกติ

### 3.1 พฤติกรรม x ผลลัพธ์สุขภาพ — "ออกกำลังกายแล้วไม่อ้วนจริงไหม?"

> **ประเด็นจากผู้ว่า:** ต้องการเห็นปัจจัยทั้งบวกและลบที่ส่งผลต่อสุขภาพจริง

| คำถามเชิงนโยบาย | ตัวแปร Input | ตัวแปร Output | วิธีวิเคราะห์ |
|---|---|---|---|
| **ออกกำลังกายแล้วไม่อ้วนจริงไหม?** | `EXCERCISE` (homehealth) | `RISKBMI`, `WEIGHT`, `WSTL` (vitalsignslf) | เปรียบเทียบ BMI เฉลี่ย: กลุ่มออกกำลัง vs ไม่ออก — แยกตามเพศ/อายุ |
| **กินเค็มแล้วเป็นความดันจริงไหม?** | `FDSLT` (homehealth) | `HPT`, `HBPN`, `LBPN` (vitalsignslf) | อัตรา HPT ในกลุ่มกินเค็มมาก vs ปกติ |
| **กินหวานเสี่ยงเบาหวานจริงไหม?** | `FDSW` (homehealth) | `DM`, `RISKDM`, `FBS` (vitalsignslf/labhealth) | อัตรา DM + FBS เฉลี่ย ในกลุ่มชอบหวาน vs ไม่ชอบ |
| **กินมันทำไขมันขึ้นจริงไหม?** | `FDFAT` (homehealth) | `CHLTR`, `CHOLEST`, `LDL`, `TRIGLY` (labhealth) | ค่าไขมันเฉลี่ยในกลุ่มชอบมัน vs ปกติ |
| **สูบบุหรี่ทำปอดพังจริงไหม?** | `SMOKE`, `SMOKETYPE1`–`4` (vitalsignslf) | `ASTH`, `EMPHY` (homehealth), `CHEST` (vitalsignslf) | อัตรา CXR ผิดปกติ/หอบหืด/ถุงลมฯ ในผู้สูบ vs ไม่สูบ |
| **ดื่มเหล้าทำตับพังจริงไหม?** | `ALCOHAL` (vitalsignslf) | `SGOT`, `SGPT`, `LIVER` (labhealth) | ค่า SGOT/SGPT เฉลี่ยในผู้ดื่ม vs ไม่ดื่ม |
| **เครียดทำป่วยจริงไหม?** | `ST501`–`ST505` (vitalsignslf) | `DM`, `HPT`, `HRT` (vitalsignslf) | อัตรา NCD ในกลุ่มเครียดมาก vs น้อย |
| **ชั่วโมงทำงานมากลาป่วยมากจริงไหม?** | `HOURLIST` (vitalsignslf) | `WDSICK` (vitalsignslf), NCD flags | Correlation ชั่วโมง vs วันลาป่วย |

**Output สำหรับผู้ว่า:** กราฟ bar chart เปรียบเทียบ 2 กลุ่ม พร้อมตัวเลข % ที่ชัดเจน เช่น "คนที่ออกกำลังกายสม่ำเสมอ อ้วนน้อยกว่า 35%"
